# Available Riding Data — Yamaha Y-TRAC Rev

Source: https://global.yamaha-motor.com/business/mc/connectivity/ytracrev/ridingdata/
Retrieved: 2026-08-20
Applies to: Yamaha R9, 2026 model (Y-TRAC Rev telemetry app)

This is the official list of riding data items Yamaha's Y-TRAC Rev app displays,
as published on the page above. This is the reference list of *what* data exists;
[pre-bike-mapping.md](pre-bike-mapping.md) tracks *how* to extract each item from the
motorcycle's CAN bus.

## Graph Items

| Item Name | Displayed Name | Description |
|---|---|---|
| Engine RPM | E/G-RPM | Data indicating the number of rotations per minute of the crankshaft |
| Gear position | Gear | Displays the current gear position. Assists in making appropriate gear selections |
| Throttle position | TPS | Indicates the degree of throttle valve opening based on throttle operation |
| Water temperature | Water-Temp | Displays the coolant temperature of the engine cooling system |
| Intake air temperature | Air-Temp | Indicates the temperature of the air taken into the engine's intake port |
| Fuel consumption | Fuel | Shows the amount of fuel consumed during riding |
| G-sensor (X-axis) | Acc-X | Measures the acceleration in the longitudinal direction of the vehicle |
| G-sensor (Y-axis) | Acc-Y | Measures the acceleration in the lateral direction of the vehicle |
| Lean angle | Lean | Measures the lean angle of the vehicle |
| Pitching angle | Pitch | Indicates the tilt of the vehicle in the longitudinal direction |
| Vehicle speed (front) | F-Speed | Measures the rotational speed of the front wheel |
| Vehicle speed (rear) | R-Speed | Measures the rotational speed of the rear wheel |
| Accelerator opening | APS | Indicates the rotation angle of the throttle grip operated by the rider |
| PWR setpoint | PWR | Changes throttle response. The lower the number, the sportier the engine character |
| TCS set value | TCS | Detects differences in speed between the front and rear wheels |
| QS△ set value | QS△ | Indicates the operational settings for upshifts using the quick shifter |
| QS▽ set value | QS▽ | Indicates the operational settings for downshifts using the quick shifter |
| SCS set value | SCS | Detects slides at the rear tire and adjusts engine output to control the slide |
| LIF setpoint | LIF | Detects if the front tire rises off the surface when launching |
| LCS setpoint | LCS | Records the mode used during launch control |
| EBM setpoint | EBM | Controls the level of engine braking when closing the throttle |
| BSR set value | BSR | When the rear wheel locks up, this system controls engine torque |

## Flag Items

| Item Name | Displayed Name | Description |
|---|---|---|
| TCS activation flag | TCS_flg | Flag information indicating that the traction control system was activated |
| SCS activation flag | SCS_flg | Flag information indicating that the slide control system was activated |
| FUP activation flag | LIF_flg | Flag information indicating that the lift control system was activated |
| BSR activation flag | BSR_flg | Flag information indicating that brake slide reduction was activated |
| LC activation flag | LC | Flag information indicating that the launch control system was enabled |

## Notes

- The Y-TRAC Rev page does not publish units, byte offsets, or scaling — only
  human-readable names and descriptions. Everything below the "displayed name"
  column had to be reverse engineered/sourced separately (see
  [pre-bike-mapping.md](pre-bike-mapping.md)).
- Non-CAN items shown elsewhere on the page (lap times, GPS path, weather,
  track name, rider notes, etc.) are log/session metadata generated by the
  app or a GPS puck, not raw CAN signals, so they are excluded from this list.
